## Как запустить проект

- Склонировать проект
- Установить зависимости - npm install
- Запустить json-server - npx json-server db.json
- Добавить в url любой id для документа, например 1

## Плюсы и минусы реализации

### Плюсы

- **Современный Angular-стек.** Standalone-компоненты, сигналы (`signal`, `computed`, `effect`), `input()` вместо `@Input`, `viewChild.required`, новый control flow (`@for`, `@if`). Отписки сделаны через `takeUntilDestroyed`.
- **Координаты аннотаций не зависят от масштаба.** Позиция хранится в «логических» пикселях страницы (делится на `zoom` при клике и перетаскивании и умножается при отрисовке). При смене масштаба аннотации остаются на своих местах.
- **Масштаб задаётся одной CSS-переменной `--zoom`.** Размеры страницы и отступы считаются через `calc()`, переход анимирован через `transition`. Страница перерисовывается в реальном размере, а не через `transform: scale`, поэтому текст и картинки остаются чёткими.
- **Перетаскивание на Pointer Events с `setPointerCapture`.** Работает мышью, на тачпаде и на сенсорных экранах (`touch-action: none`) без сторонних библиотек.
- **Два типа аннотаций:** текст и картинка (с предпросмотром перед добавлением).
- **Готовые UI-компоненты Taiga UI** (select, input, input-files).

### Минусы

- Аннотации живут только в памяти: кнопка «Сохранить» лишь выводит документ в `console.log`, после перезагрузки страницы всё теряется.
- `Annotations` — глобальный синглтон, не привязанный к `documentId`. При переходе на другой документ аннотации предыдущего остаются.
- Параметр маршрута `:id` не используется при загрузке: `getDocs()` всегда возвращает одни и те же страницы. Для пути `/` маршрута нет, и отображается пустая страница.
- Аннотации адресуются по индексу в массиве, а не по уникальному `id`.

## Известные проблемы и способы решения

| Проблема                                                                                  | Причина                                                                 | Решение                                                                                                       |
| ----------------------------------------------------------------------------------------- | ----------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------- |
| Аннотация отображается на всех страницах                                                  | В `db.json` у страниц нет `id`, json-server не добавляет его при чтении | Добавить `id` каждой странице в `db.json`                                                                     |
| Картинки-аннотации не переживают перезагрузку и копят память                              | Используется `URL.                                                      |
| Аннотации не сохраняются                                                                  | «Сохранить» только логирует в консоль                                   | `POST`/`PUT` в json-server (например, `/annotations?documentId=...`) или `localStorage` как временный вариант |
| Нельзя закрыть редактор кликом вне его или клавишей Esc, текст не подтверждается по Enter | Не реализовано                                                          | Добавить `(keydown.enter)`, `(keydown.escape)` и обработчик клика снаружи (`tuiActiveZone` / `tuiObscured`)   |
| Медленная работа на больших документах                                                    | Рендерятся все страницы целиком                                         | `loading="lazy"` для изображений, виртуальный скролл (`@angular/cdk/scrolling`)                               |
| Нет доступности с клавиатуры                                                              | Аннотации создаются только кликом по `<img>`                            | Добавить `tabindex`, `role`, `aria-label` и управление с клавиатуры                                           |
